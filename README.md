# Simple WhatsApp Bot

## Local setup
1. Copy `.env.example` to `.env`
2. Fill `WHATSAPP_TOKEN` and `PHONE_NUMBER_ID`
3. Run:
   npm install
   npm start

## Webhook
- Callback URL: `https://YOUR-SERVICE.onrender.com/webhook`
- Verify token: use exactly the same value as `VERIFY_TOKEN`

## Test
Send `Привет` to the Meta test WhatsApp number.
